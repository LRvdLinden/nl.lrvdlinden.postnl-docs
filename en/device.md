# Device data

The My PostNL device exposes the values below. Parcel fields provide a summary; use parcel trigger tokens for data belonging to a specific event.

| Value | Type |
| --- | --- |
| Mail expected | boolean |
| Mail items | number |
| Parcels underway | number |
| Next delivery | string |
| Delivery date | string |
| Delivery window | string |
| Parcel status | string |
| Parcel sender | string |
| Parcel receiver | string |
| Tracking number | string |
| Latest parcel event | string |
| Parcel status time | string |
| Parcel delivered | boolean |
| Shipment type | string |
| Parcel weight | string |
| Parcel dimensions | string |
| Connection status | string |
| Last update | string |


The device also exposes images for the latest mail item and **My Delivery**. A mail scan is only available when it can be retrieved.
