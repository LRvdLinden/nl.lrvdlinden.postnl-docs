# My Delivery

A visual delivery overview with the PostNL van, parcel status and delivery window. Progress represents the available delivery information; the van is not a live GPS location of the driver.

![My Delivery – light](../.gitbook/assets/pakket-details-light.png)

![My Delivery – dark](../.gitbook/assets/pakket-details-dark.png)

Select the correct My PostNL device when adding the widget. See [Troubleshooting](../troubleshooting.md) if data is missing.
