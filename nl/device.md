# Apparaatgegevens

Het Mijn PostNL-apparaat biedt onderstaande waarden. Pakketvelden vormen een samenvatting; gebruik de pakkettrigger-tokens voor de gegevens van een specifieke gebeurtenis.

| Waarde | Type |
| --- | --- |
| Post verwacht | boolean |
| Poststukken | number |
| Pakketten onderweg | number |
| Volgende bezorging | string |
| Bezorgdatum | string |
| Bezorgvenster | string |
| Pakketstatus | string |
| Afzender pakket | string |
| Ontvanger pakket | string |
| Trackingnummer | string |
| Laatste pakketgebeurtenis | string |
| Tijdstip pakketstatus | string |
| Pakket bezorgd | boolean |
| Type zending | string |
| Gewicht pakket | string |
| Afmetingen pakket | string |
| Verbindingsstatus | string |
| Laatste update | string |


Daarnaast stelt het apparaat afbeeldingen beschikbaar voor het laatste poststuk en **Mijn Bezorging**. Een postscan is alleen beschikbaar als die kan worden opgehaald.
